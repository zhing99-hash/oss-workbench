# Changelog

## 0.1.0 - 2026-11-20

Initial public MVP.

- Local-first MCP server for GitHub open-source project management.
- Interactive MCP Apps workbench with browser fallback.
- GitHub account sync for public, owned, non-fork and non-archived repositories.
- Maintainer task scanning for issues, pull requests, CI failures, stale items and project documentation.
- Two-phase GitHub writes: prepare, preview, confirm, audit.
- Project health, achievements and open-source statistics with explicit data limitations.
- Install adapters and tutorials for WorkBuddy, DeepSeek Harness, Codex and OpenClaw.
- Local SQLite storage, stdio MCP and Streamable HTTP mode.
- Unit tests for task rules and two-phase actions; MCP contract test.
